# Product context

Одностраничное русскоязычное портфолио Бориса Басова для рекрутеров и frontend-команд. Основная задача — быстро доказать компетентность React Frontend Developer через реальные интерфейсы, системное мышление, тестирование и ясный контактный сценарий.

## Пользователи и сценарии

- Рекрутер за 1–2 минуты понимает специализацию, опыт и получает резюме.
- Frontend-лид оценивает качество проектов, стек и инженерный подход.
- Посетитель может связаться по email, телефону или Telegram.

## Ограничения

- Только подтверждённые факты из резюме и репозиториев.
- SENSE показан как именованный коммерческий кейс: официальный бренд и реальные компоненты из Storybook на тестовых данных. Рабочие экраны, корпоративный код, внутренние ссылки и production-данные не публикуются.
- «Музей криптографии» показан как именованный публичный кейс без NDA: реальные кадры V1/V2, открытые исходники и технические показатели из аудита репозитория. Skillbox упоминается только как контекст учебного проекта.
- Продуктовые метрики из резюме публикуются только как приблизительные. Технические показатели открытых проектов можно приводить точно, если они подтверждены текущим прогоном тестов или сохранённым аудитом.
- Статический GitHub Pages без CMS, backend и аналитики.

# Design context

## Direction

Точная инженерная эстетика с редакционной асимметрией: холодная светлая база, глубокий сине-графитовый текст и один сигнальный оранжевый акцент. Тёмная тема сохраняет иерархию. Реальные интерфейсы — главный визуальный материал.

## Type and layout

- Onest, self-hosted, с кириллицей.
- Сильная шкала заголовков, компактные служебные подписи, заметный отрицательный трекинг только на display-тексте.
- Макет до 1440 px, явная одноколоночная перестройка ниже 768 px.
- Не использовать стеклянные карточки, декоративный код, градиентные «AI»-фоны и одинаковые плитки.

## Motion

- Hero: 450 мс, cubic-bezier(0.23, 1, 0.32, 1), stagger 60 мс.
- Секции: IntersectionObserver, только transform и opacity.
- Hover/press: 120–160 мс и только для точного указателя.
- Reduced motion убирает перемещение.

## Accessibility

- WCAG AA, заметный focus-visible, skip-link, семантические заголовки.
- Интерактивные области не меньше 44×44 px.
- Управление темой, меню и демонстрацией доступно с клавиатуры.

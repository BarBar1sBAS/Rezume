# Портфолио Бориса Басова

Одностраничное портфолио React Frontend Developer: React, TypeScript, Vite и обычный CSS.

```bash
npm ci
npm run dev
npm run lint
npm run build
npm run test:e2e
```

Публикация выполняется официальным GitHub Pages workflow из ветки `main`.

## Кейс «Зацеп»

Размещён между SENSE и Музеем криптографии, прямая ссылка — `/Rezume/#zacep`.

- [Продуктовые макеты в Figma](https://www.figma.com/design/33uZlvdpstuANY0xc0tvUf?node-id=131-2406) и [UI kit](https://www.figma.com/design/33uZlvdpstuANY0xc0tvUf?node-id=133-2407).
- [Опубликованный сайт](https://barbar1sbas.github.io/zacep/) и [репозиторий](https://github.com/BarBar1sBAS/zacep).
- Показатели 165 UI-проверок и шесть размеров экрана взяты из [журнала от 28 октября 2026 года](https://github.com/BarBar1sBAS/zacep/blob/dfffe9e/tests/TDD.md). Это проверка проекта «Зацеп», а не тесты портфолио.

Изображения в `public/assets/zacep/`: свежие кадры главной, мобильной версии и страницы кейса сняты с опубликованного сайта 29 октября 2026 года; каркас, продуктовый макет, варианты компонентов и Storybook взяты из сохранённых материалов проекта. Экспорты Figma показывают этап дизайна, до обновления палитры сайта. Прозрачный фон компонентов сохранён визуально на бумажной подложке брендбука. Варианты WebP подготовлены для ширин 720 и до 1200 px, мобильный кадр — 390 px.

Проверки портфолио включают порядок кейсов, прямой якорь, ссылки, загрузку изображений, появление блоков при прокрутке и обе темы на 320 / 390 / 768 / 1024 / 1440 px. Форма на сайте «Зацепа» пока не отправляет заявки; статус демоверсии явно указан в кейсе.
